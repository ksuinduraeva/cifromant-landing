# Контекст бота Цифромант

Справка о боте для работы **из репозитория лендинга**. Актуально на 14.07.2026.

Telegram-бот с платной подпиской. Считает нумерологические числа по дате рождения и имени, отправляет персональный AI-прогноз каждое утро подписчикам.

**Бот:** @number_day_bot (прод), @number_day_test_bot (тест)
**Хостинг бота:** Railway (две среды: dev и prod)
**БД:** Supabase PostgreSQL (два проекта: dev и prod)
**Код бота:** `../bot` (соседняя папка)

> Общий план проекта по фазам — в `CLAUDE.md` (раздел «План проекта по фазам»), он одинаков в обоих репозиториях. Здесь — только справка о том, как устроен бот, чтобы писать статьи и лендинг, не открывая его код.

## Стек бота

- **Node.js** + **Telegraf** v4 — логика бота
- **pg** (node-postgres) + **Supabase** — PostgreSQL БД
- **OpenAI API** — модель `gpt-5.4-mini-2026-03-17` (день, месяц, год, совместимость). Исключение: склонение имени партнёра — служебный вызов на `gpt-4o-mini`
- **Express** — сервер для вебхука YooKassa
- **node-cron** — рассылка в 08:00 по местному времени пользователя
- **YooKassa** — приём платежей

## Подписка и монетизация

- **29 ₽/день** — пробный день
- **99 ₽/неделя** + 1 день в подарок
- **299 ₽/месяц** + 7 дней в подарок
- Оплата через YooKassa, вебхук верифицируется обратным запросом к API
- **Реферальная система:** за первую оплату приглашённого друга — бонусные дни (неделя → +1 день, месяц → +7 дней). Правило «первый выигрывает»

## Ежедневный прогноз — как он устроен сейчас (после Фазы 12)

Это **главная фишка продукта** и то, что продаёт подписку. Переработан 02–03.07.2026, на проде.

**Три уровня:**
- **Уровень 0** (без подписки) — шаблонный текст числа дня + честная подпись «общий настрой для всех с этим числом». Задача — показать контраст с персональным.
- **Уровень 1** (подписчик) — короткий персональный прогноз каждое утро + кнопка «🔮 Раскрыть подробнее».
- **Уровень 2** (по кнопке) — разбор по сферам: 💼 дела и работа / 💜 отношения / 🌿 состояние + практика **или** вопрос дня.

**Почему он не однообразный:** пул из 7 форматов (будни короче, выходные глубже, дни-пики особые), а тема, энергия и призыв меняются вместе с личным числом дня. Жёсткой структуры «5 разделов» больше нет — раньше она и делала прогноз одинаковым.

⚠️ **Для маркетинга:** механику теперь можно описывать честно (Фаза 12 закрыта). Раньше действовало ограничение «только стабильная ценность, без деталей» — оно снято.

## AI-прогнозы — правила промптов (общие)

- Только русский язык — ни одного английского слова
- Никаких обещаний будущего («произойдёт», «случится», «будет»)
- Никакой мистики, пафоса и эзотерического жаргона; запрет вычурных слов
- Никаких медицинских и финансовых советов
- Обращение на «ты», тепло и конкретно, с заземлением в быт
- Числа пользователя названы прямо в тексте («число судьбы 3», «личный день 5»)
- Прогноз нельзя переслать другому — он про уникальное сочетание чисел

**Структура месячного прогноза:** тема месяца → что в росте → на чём фокус → что учитывать → вопрос месяца.
**Структура годового:** главная тема года → возможности → что трансформируется → задача года → вопрос года.
**Совместимость (7 разделов):** характеры и роли → атмосфера → притяжение и близость → сила вместе → трения → над чем работать → вопрос для пары.

## Нумерологические расчёты

- **Число дня рождения** — день рождения (сводится к одному числу)
- **Число судьбы** — сумма всех цифр полной даты рождения
- **Число самовыражения** — числовое значение всех букв ФИО при рождении
- **Число души** — числовое значение гласных букв ФИО при рождении
- **Личный день/месяц/год** — персональные циклы от даты рождения
- Мастер-числа (11, 22, 33) не сводятся дальше

⚠️ **Терминология:** для пользователя это всегда **«число судьбы»** (не «число жизненного пути» — его ищут в ~8,5 раз реже). В коде бота остались старые имена (`lifePathTexts`, `lifePathNumber`) — это намеренно, переименованы только видимые строки.

📌 Формулы расчёта живут в `../bot/src/numerology/index.js`. Когда сделаем Фазу 13 (калькулятор на сайте), логика **задублируется** в браузерном компоненте — при правке формул держать в голове обе копии.

## Статичные тексты (../bot/src/texts/index.js)

Для каждого числа (1–9, 11, 22, 33) есть готовые описания: число дня рождения, число судьбы (+ версии «для другого человека»), число самовыражения, число души, личное число дня.

Тексты: на «ты», гендерно нейтральные, тёплые и конкретные, без мистики.
Правила их написания — `../bot/TEXTS_RULES.md`.

⚠️ Для статей лендинга описания чисел пишем **своими словами**, не копируя тексты бота — иначе дубли контента вредят SEO.

## Tone of voice продукта (общий для бота и сайта)

- Нумерология — не мистика, а закономерности
- Тексты на «ты», тепло, без снисхождения
- Конкретно — не «энергия числа», а «для тебя с числом судьбы 3 это проявляется так...»
- Без обещаний («произойдёт», «ждёт тебя») — только про текущее состояние и возможности
- Акцент на уникальность: прогноз — только для этого человека, с его числами
